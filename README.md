# Food-vending-machine
This is a simple Java console application that simulates a restaurant ordering system.
- The program greets the user and asks for their name.
- It displays a menu with items such as Chicken Biryani, Cauliflower Curry, Paneer Curry, Dal, and Chapati, along with their prices.
- The user selects an item, enters the quantity, and is shown the total cost.
- The program then asks for payment input and validates whether the entered amount matches the required total.
- If the payment is correct, the order is confirmed; otherwise, the user is prompted to enter a valid amount.
